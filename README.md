# 基金阶梯账本（Fund BOLL Ledger）

一款面向个人使用的场内基金手动记账 PWA。用于 Windows 电脑与 Android 手机，不接入东方财富账户、不拉取行情、不连接券商、不自动下单。

> 本项目当前是供本地拉取和验证的 MVP 起点。账本数据默认保存在当前浏览器的 IndexedDB 中。不同设备的数据不会自动同步；可用 JSON 备份手动迁移。

## 首版交付范围

- **基金档案**：手动维护基金名称、代码、市场、类别、最小价格变动单位与东方财富账户佣金估算参数。
- **五个价格基准**：BOLL 上轨、中轨、下轨、昨日收盘价、上一次成交价。另有独立的手动当前价格输入。
- **实时重算**：当前输入价会分别对比五个基准，显示涨跌额、涨跌幅与高于/低于基准的位置。
- **十档价格阶梯**：对选定基准生成向上和向下 1%—10% 阶梯；每一档相对原始基准独立计算，并按该基金配置的最小价格变动单位舍入。当前价会标注已越过、下一档、尚未到达或超出十档范围。
- **交易明细**：逐笔记录日期时间、买/卖、价格、份额、佣金、经手/过户等费用、印花税、其他费用与备注；允许编辑、删除，并标记费用是否已对照东方财富实际成交明细核对。
- **持仓与盈亏**：加权平均成本法，买入费用纳入持仓成本；卖出费用计入已实现盈亏；展示当前持仓、成本、已实现盈亏、浮动盈亏与费用拆分。
- **价格历史**：主动保存当日输入的五个基准、当前价、报价单位和备注。
- **备份**：完整 JSON 导入/导出；交易明细 CSV 导出。
- **本地优先与 PWA**：支持安装到桌面/主屏幕；Service Worker 提供基础缓存。无账号、无云端数据传输。

## 发布到 GitHub

当前交付包尚未推送到远端：本次可用的 GitHub 连接没有创建新仓库的操作。Windows 安装 GitHub CLI 后，先运行 `gh auth login`，再在项目根目录用 PowerShell 执行 `./scripts/publish-to-github.ps1`。脚本会把代码提交到本地 Git，并尝试创建 **私有** 仓库 `just2512/fund-boll-ledger` 后推送 `main`。默认私有是为了避免在未明确选择公开范围前公开发布。

## 本地运行

需要 Node.js 20 或更高版本。首次安装依赖需要网络访问 npm registry。

```bash
npm install
npm run test          # 单元测试（计算核心 + 边界）
npm run build         # tsc 类型检查 + Vite 生产构建
npm run dev           # 本地开发服务器
npx playwright test   # 端到端测试（使用系统 Edge，真实交互）
```

打开终端中 Vite 提示的本地地址。Windows 与 Android 可分别使用 Edge/Chrome 访问同一部署地址。要在 Android 手机上从电脑访问开发服务器，电脑和手机需位于可互相访问的网络，且要允许相应防火墙端口；PWA 安装/Service Worker 正常工作通常需要 HTTPS，`localhost` 属于本地开发例外。

## 使用流程

1. 点击“新增基金”，输入名称、代码和类别。
2. 确认该基金报价最小变动单位（场内基金常用单位为 0.001 元，但应按实际品种规则核实）。
3. 填写上轨、中轨、下轨、昨日收盘价、上一次成交价与当前价格。
4. 选择阶梯基准和方向，观察十档价格与当前价格的位置。
5. 在“交易账本”输入实际成交价格、份额和实际费用；佣金估算仅作录入辅助。
6. 在“价格计算”保存价格快照，并定期导出 JSON 备份。

## 费用规则

- 基金档案可保存佣金费率（以百分比形式输入，例如 `0.025` 代表 `0.025%`）、可选最低佣金和是否启用最低佣金规则。
- 只有佣金会根据用户配置生成估算值；经手/过户等费用、印花税、其他费用均手动录入，不根据基金类别自动推断。
- 实际账本使用每笔交易保存的费用值。应核对东方财富实际成交记录或交割单，避免重复记入已包含在佣金中的费用。
- 对费用规则不确定时，留空费率并逐笔按实际发生额录入，不要用未经核实的模板代替事实。

## 会计与价格口径

- **涨跌幅**：`(当前价 - 基准价) / 基准价 × 100%`。
- **价格阶梯**：`基准价 × (1 ± n/100)`，`n` 为 1—10；不复利、不以上一档为新基准。
- **买入成本**：成交额 + 买入费用。
- **卖出已实现盈亏**：卖出成交额 − 卖出费用 − 卖出份额对应的加权平均成本。
- **浮动盈亏**：当前参考市值 − 剩余持仓成本；不扣未来卖出费用。
- 成交额和费用均以分为单位做固定点核算；价格用六位小数定点表示。报价价格阶梯按设置的价格最小变动单位舍入。
- 每笔卖出都按成交时间校验当时是否有足够份额；禁止悄悄形成负持仓。

## 已知边界（首版明确不做）

- 不连接东方财富账户、行情接口、券商 API 或自动交易。
- 不承诺当前输入价是真正实时行情；价格需用户从自己使用的行情来源手动查看后录入。
- 不自动判断某类基金适用的佣金、最低佣金、印花税减免或交易所费用规则。
- 无云同步、多设备冲突解决、账号系统、云端备份或服务端数据。
- 当前账本的持仓与盈亏是根据用户已录入交易推算的结果；漏记、错记、交易时间错误都会影响结果。
