# MACD EMA 历史起点敏感性报告

## 范围与方法

本报告不修改 MACD(12,26,9) 公式，也不更改“首个输入值作为 EMA seed”的现有规则。目的在于验证：同一确认收盘日期下，改变已加载历史序列的起点，会不会改变最新 DIF、DEA、柱体或 MACD 分类。

真实数据验收：

- Actions Run：`42599861183`
- 主线提交：`bace9d2b3647ffa50190fc119bff7f4cdf088f6b`
- Artifact：`13665332001`（有效期至 2026-12-09）
- 标的：510300、510500、159915、512100
- 周期：日线、周线、月线，共 12 组
- 确认 K 线总数：3,193；来源策略违规数：0
- 每个周期都在相同 as-of 日期上比较完整历史前缀与不同长度的尾部历史后缀。

候选长度：35、50、75、100、160、240 根。滚动分析对每个可用历史 as-of 日期重复比较；每个候选只使用该 as-of 日期及之前的数据，不读取未来 K 线。

数值差异以同一 as-of 日期的收盘价为基准，换算为基点（bps）：

`abs(candidate - full-prefix reference) / asOfClose × 10,000`

分类差异检查六个字段：`zeroAxis`、`lineRelation`、`crossEvent`、`lastCross`、`arrangement`、`momentum`。一个日期只要其中任一字段不同，就计为一次分类不一致；不是按字段数量重复计数。

- 35、50、75、100 根候选均覆盖 12 组序列。

## 关键事实

1. **35 根不能作为信号稳定性的依据。** 滚动窗口内出现 428 个分类不一致日期。最新端点中，159915 月线完整历史显示当日新死叉，而 35 根后缀显示没有新交叉，`crossEvent` 与 `arrangement` 均发生变化。
2. **50 根仍存在明显差异。** 2,593 个比较中有 165 个日期分类不一致；即使某些最新端点分类相同，数值差异仍可能很大。
3. **75 根仍不能保证分类一致。** 仍有 21 个日期不一致。
4. **100 根接近稳定但没有完全通过。** 1,993 个比较中仍有 3 个分类不一致日期，集中在 512100 日线/周线；因此不能把 100 根写成已验证的稳定门槛。
5. **160 根是本次样本中第一个没有观察到分类不一致的候选。** 1,313 个比较全部一致，DIF/DEA/柱体最大差异均低于 0.04 bps。
6. **240 根数值差异更小。** 636 个比较均无分类差异，但覆盖不到月线，不能据此把 240 根作为全周期要求。

## 当前结论

- 当前 MACD 公式、EMA seed 和 35 根最低计算门槛均未修改。
- 本次数据支持把 **160 根作为后续生产信号门槛的首选候选**，但它不是已经冻结的生产默认值。
- 512100 月线目前只有 120 根确认历史；如果最终采用 160 根硬门槛，该周期必须返回 UNKNOWN/INSUFFICIENT，不能用 120 根结果冒充已验证稳定。
- 本次比较以当前应用可加载的最多 320 根为参考，不等于完整上市历史，也不能证明未来所有行情都满足同样边界。
- MACD 数值可以计算，不等于 MACD 交叉分类已经具备可用于交易判断的稳定性。

## 尚未完成的决策与门槛

1. 冻结历史不足 160 根时的业务语义：仅标记信号 UNKNOWN，还是整个 MACD 状态返回 INSUFFICIENT。冻结前不改变现有生产行为。
2. 对 160 根候选继续做跨行情阶段、不同数据源和更长历史窗口的复核。
3. BOLL 状态参数仍未通过滚动样本外策略验证，不能把当前 one-factor 敏感性结果解释为收益优势。
4. 上述门槛完成前，不启动现有价格对比模块 UI 改造，不把任何候选参数写成买卖判断。
