## 6. 解释边界

1. BOLL 分位是各自历史窗口内的位置，不是未来方向概率。
2. BOLL 状态参数是描述性分类基线，不是买卖阈值。
3. MACD 稳定性门槛只减少历史起点造成的状态漂移，不代表信号有效。
4. 所有周期独立显示；综合描述只并列指标事实，不输出买卖方向。
5. 本报告没有策略收益、订单、成交、持仓或账本模拟。
