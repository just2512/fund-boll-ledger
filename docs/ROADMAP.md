# 迭代路线图

## MVP 当前范围

- [x] PWA 基础壳、响应式桌面/手机界面
- [x] Fund / Trade / Snapshot 数据模型
- [x] 五基准对比与当前价手动输入
- [x] 双向 1%—10% 价格阶梯与越档定位
- [x] 可配置最小价格变动单位
- [x] 手动交易明细、费用拆分、交易编辑/删除
- [x] 加权平均成本、已实现/浮动盈亏计算
- [x] 价格快照、JSON 备份恢复、CSV 交易导出
- [x] 核心公式测试初稿
- [ ] 依赖安装后跑通单测与生产构建
- [ ] 在真实 Android / Windows 设备上手动验收
- [ ] 用用户真实成交明细复核手续费口径

## MVP 验证后

- [ ] 对价格/金额处理做边界覆盖：零/负数、超大数、更多价格精度、小数手续费、非法导入。
- [ ] 备份导入前验证交易序列与份额可行性；给出修复报告而不是直接接受有矛盾的数据。
- [ ] 将 IndexedDB 状态保存从“单一大对象”升级为按实体存储并进行 schema 迁移。
- [ ] 增加账本完整性审计页：是否存在未记录费用、无当前价基金、缺失上一成交价、超卖记录或重复交易。
- [ ] 加入交易筛选和按日期/基金/买卖方向搜索。
- [ ] 生成历史快照对应的五基准涨跌幅回顾。

## 明确推迟

- 云端多设备同步、用户账号、远程备份。
- 自动行情与东方财富登录/账户接口。
- 自动交易、交易信号和策略回测。
- 自动猜测基金类别对应的收费规则。

任何远程同步需求都要先确认用户授权、加密、冲突处理、账户恢复与服务成本，再进入开发；不将本地账本无提示上传。
