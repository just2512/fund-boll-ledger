# C 线：历史逐根重放与防未来数据测试任务交接

基线：契约冻结后的 `main`。
共享契约：`docs/TECHNICAL_STATE_COMPUTATION_CONTRACT.md`、`src/technical-state/types.ts`。

## 责任范围

实现纯函数历史数据规范化、确认收盘序列构建和逐根重放/验证框架。不得复制或简化 BOLL/MACD 公式；重放器通过注入计算回调调用正式引擎。

## 必须完成

- [ ] 将原始字符串/数值 K 线规范化为升序唯一序列。
- [ ] 非法日期/价格留下可诊断错误；同日相同收盘价可去重；同日不同收盘价返回 INVALID。
- [ ] 复用契约中的周一周键、YYYY-MM 月键和日/周/月收盘确认语义。
- [ ] 缺少可信交易日期时 fail closed；周/月同周期 K 线不得因周中 15:00 被确认。
- [ ] 构建逐根推进器，每个 asOfDate 只向回调提供截至该日的已确认前缀。
- [ ] 建立未来数据隔离：追加未来 K 线不能改变以前日期结果。
- [ ] 建立全量计算与相同起点逐根前缀结果一致性测试。
- [ ] 建立重复/冲突日期、缺失行、异常行、未收盘周期、不同数据源来源标记测试。
- [ ] 提供最多 320 根历史窗口下的覆盖范围元数据，不声称验证未加载历史。

## 禁止事项

- 不另写 BOLL/MACD 指标算法。
- 不修改 `src/macd.ts` 或 `src/market-data.ts`；必要的集成适配由 main 在合并阶段完成。
- 不修改 UI 和账本 schema。
- 不以只测最近一根替代历史逐根验证。

## 交付

新增 `src/technical-state/series.ts`、`history-replay.ts` 及独立测试（文件名可按实际结构调整）。提交前运行 `npm run test`、`npm run build`，修复真实失败并保留日志。该分支 push 会触发 Frontend Checks。
