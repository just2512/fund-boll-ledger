# 执行契约（强制）

本文件是 `BOLL + MACD 技术状态与 A/B 双线工作` 的长期执行约束。每次新会话、上下文恢复、中断续作前，必须先读取本文件、需求台账和实施计划；不得依赖聊天记忆恢复任务。

## 1. 唯一范围基线

- 完整需求和阶段顺序以 [技术状态分析实施计划](TECHNICAL_STATE_ANALYSIS_IMPLEMENTATION_PLAN.md) 为准，尤其是第 21、22 节的 A/B 双线边界与最新执行记录。
- 机器可检查的逐项状态以 [需求验收台账](TECHNICAL_STATE_REQUIREMENTS.json) 为准。
- 本契约不授权增加任何产品功能，也不允许删除、合并、降级原有需求。
- 如本文、实施计划、台账出现冲突，停止受影响工作，先查明并记录冲突；不得自行选择较容易完成的版本。

## 2. 不可突破的范围边界

1. A/B 两条工作线独立推进、独立 CI；只在真实代码依赖处汇合。
2. A 线只维护并验收技术计算事实和描述性 UI。不得加入买卖建议、策略收益、资金占用或未经验证的策略结果。
3. B 线只按实施计划推进 OHLCV 数据、数据契约、事件到交易模拟的衔接、回测和样本外验证。不得把技术状态直接包装成交易指令。
4. B 线的复权口径、成交量单位、超时、入场/成交、退出、资金分配、ETF 交易单位、费用/滑点及训练/OOS 窗口等未冻结事项，必须保持 UNKNOWN/MISSING；不得自行填入“合理默认值”来伪造可执行策略。
5. 不修改 Fund/Trade/Snapshot 账本结构、既有交易记录语义或 JSON 备份契约，除非用户另行明确授权。
6. 不增加后台轮询、账户连接、自动交易、云同步、策略信号推送或独立产品模块。

## 3. 修改规则

- 每项代码修改必须关联本台账中的需求 ID，并能说明为何是实现该项验收条件所必需。
- 先审计并复用现有代码；禁止平行重写已有 MACD、BOLL、行情请求或历史重放能力。
- 不做无关格式化、目录搬迁、依赖替换或顺手优化。
- 发现范围外问题只记录，不实施。
- 遇到需求冲突、架构契约变化、安全风险、不可逆数据风险时，停止受影响工作；普通 CI 失败必须定位并修复，不能跳过。

## 4. 状态和证据规则

状态只允许使用：

- `NOT_STARTED`
- `IN_PROGRESS`
- `PASS`
- `FAIL`
- `BLOCKED`
- `MISSING`
- `UNKNOWN`

规则：

1. 只有真实代码实现、对应验收测试通过、相关 CI 成功且证据可追溯，才允许标记 `PASS`。
2. 只有文档、类型定义、空实现、未被生产调用链使用的代码，不构成实现完成。
3. 测试文件存在不等于测试通过；CI 绿色不等于业务验收完整。
4. `PASS` 必须附带提交 SHA 和可访问的 CI/验收记录链接。没有证据必须降为 `UNKNOWN`，不得猜测。
5. `MEASURED`、`DRAFT`、`NOT_FROZEN` 不等于 `PASS`。
6. 不得删除失败测试、放宽断言、减少样本、屏蔽错误或用模拟结果替代真实数据来取得绿色结果。
7. 不得将未完成项从台账删除来制造“全部完成”。

## 5. 阶段放行规则

- A 线描述性 UI 的 PASS 不代表 B 线策略研究通过。
- B 线数据采集、解析或 walk-forward 基础设施 PASS，不代表交易策略已经可以回测或发布收益结论。
- 只有 B 线全部策略契约已由用户明确冻结、交易模拟和样本外验证均通过，才允许讨论策略类 UI。
- 任何阶段的放行必须逐项满足实施计划中的硬门槛；不得以总体描述或局部成功替代。

## 6. 恢复执行固定流程

每次恢复工作按顺序执行：

1. 读取本文件、需求验收台账、实施计划和相关测试计划。
2. 获取 Git 当前分支、HEAD SHA、工作区状态及最近提交；确认目标分支，不把旧分支当作当前主线。
3. 读取最新相关 CI 的 run、job、step 和日志；不能把排队/运行中当作通过。
4. 将台账状态与当前代码、提交和 CI 重新核对；发现过期状态先修正。
5. 从已满足依赖的未完成项继续；并行线保持隔离。
6. 修改后运行定向测试；集成前运行完整前端测试、类型检查、生产构建及对应真实数据验收。
7. 更新台账时附证据；最后检查 diff，确认无范围外变更。

## 7. 完成声明

只有所有必需需求均为 `PASS`，且没有未解决的 `FAIL`、`BLOCKED`、`MISSING` 或 `UNKNOWN`，才可以声明该工作范围全部完成。外部设备、真实账户/交割单或用户专属环境无法由 CI 验证的项目，必须保留为未验收，不能用云端构建替代实机结果。

**本文件本身的提交不代表任何功能验收通过。**
